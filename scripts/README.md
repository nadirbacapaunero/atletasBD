# Scripts - Utilidades y Helpers

Lugar para scripts de soporte, utilidades de testing, y herramientas administrativas.

## Ejemplos de scripts útiles a agregar:

- `generate_encryption_key.py` - Generar clave de encriptación
- `test_mongodb_connection.py` - Testear conexión MongoDB
- `test_strava_oauth.py` - Testear flujo OAuth
- `admin_create_athlete.py` - Crear atletas manualmente
- `backup_mongodb.py` - Backup de base de datos
- `reset_sync.py` - Resetear estado de sincronización
