# Plantillas Obsidian

Templates para generar notas consistentes en Obsidian.

## Tipos de Plantillas:

1. **Athlete_Profile.md** - Perfil del atleta con datos personales
2. **Activity.md** - Nota individual de entrenamientos
3. **Daily_Metrics.md** - Resumen diario de métricas CTL/ATL/TSB
4. **Weekly_Report.md** - Reporte semanal
5. **Manual_Report.md** - Reporte manual de lesiones, sueño, etc.
6. **Query_Templates.md** - Dataview queries útiles

Estas se usan en `src/obsidian_writer.py` para generar notas automáticamente.
